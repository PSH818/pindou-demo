# 拼豆图纸 · 设计规范

> 路线A「奶茶米白系」· 治愈 · 简洁 · 暖系
> 基于 2026-06 演示页确认，适用于所有页面和组件。
>
> **代码实现**：本文档中的 token 在 `src/styles/_tokens.scss` 维护（单一来源），
> SCSS 文件通过 `@use '../../styles/tokens' as *;` 引入，禁止在组件样式里重新声明色值。
> 全局反馈（Toast/Modal/Prompt/ActionSheet）统一使用 `src/components/Feedback/`。

---

## 一、设计哲学

拼豆是重复、冥想式的手工活动。App 的视觉语言应当传递：

- **温度感**：像一杯奶茶放在阳光里，不是冷白的工具界面
- **呼吸感**：留白充足，不拥挤，让用户专注于图纸本身
- **静谧感**：颜色饱和度克制，不刺激，适合长时间使用

## 二、色彩体系

### 2.1 Token 定义

| Token 名 | 值 | 用途说明 |
|----------|-----|---------|
| `$bg` | `#FAF7F3` | 所有页面背景——暖象牙白，取代纯白 |
| `$bg-card` | `#FFFBF7` | 卡片、面板、浮层表面——奶油白 |
| `$accent` | `#F0874E` | 主色调——蜜桃橙，用于主要交互和新建图纸 |
| `$sage` | `#6BA886` | 画板专属色——薄荷鼠尾草，仅用于空白画板入口和绘图模式 |
| `$text` | `#2C1810` | 主要文字——深暖棕 |
| `$text-dim` | `#9B7E72` | 辅助/次要文字——暖灰棕 |
| `$border` | `#EDD0B8` | 边框、分隔线——燕麦米 |
| `$shadow` | `rgba(150, 70, 30, 0.10)` | 所有 box-shadow 颜色——暖棕透明，禁止用纯黑透明 |
| `$accent-light` | `rgba(240, 135, 78, 0.10)` | 橙色背景填充（选中态、hover 底色） |
| `$sage-light` | `rgba(107, 168, 134, 0.12)` | 鼠尾草色背景填充 |

### 2.2 语义色规则

**橙色（`$accent`）专用场景：**
- 新建图纸入口按钮
- 主要 CTA 按钮（开始创作、立即转换）
- 当前激活的工具高亮
- 选中状态环、进度指示

**鼠尾草绿（`$sage`）专用场景：**
- 空白画板入口按钮（边框、图标颜色、背景填充）
- 手绘模式下的特有标识

> ⚠️ 两色不可互换。橙色代表「从照片创作」，绿色代表「从空白手绘」，语义不同。

### 2.3 深色模式（暖棕夜色系）

通过 `prefers-color-scheme` 自动切换，无手动开关。实现方式：SCSS token 全部是 CSS 变量引用（`var(--x)`），浅色值定义在 `src/app.scss` 的 `:root`，深色值在其 `@media (prefers-color-scheme: dark)` 块中覆写。

| Token | 浅色 | 深色 |
|-------|------|------|
| `--bg` | `#FAF7F3` | `#221A13` |
| `--bg-card` | `#FFFBF7` | `#2E241B` |
| `--bg-muted` | `#FEF3E6` | `#3B2E22` |
| `--accent` | `#F0874E` | 不变 |
| `--accent-strong` | `#E5773A` | `#F6A473` |
| `--sage` | `#6BA886` | `#7FBD9C` |
| `--text` | `#2C1810` | `#F1E8DE` |
| `--text-dim` | `#9B7E72` | `#B49B8C` |
| `--border` | `#EDD0B8` | `#4B3B2C` |
| `--border-strong` | `#E2C2A3` | `#5D4A38` |

**规则：**
- 需要 alpha 通道时用通道变量：`rgba(var(--accent-rgb), 0.1)`，禁止 `rgba($accent, 0.1)`（token 是 var 引用，sass 无法求值）
- **图纸 Canvas 区域在深色模式下保持暖白**（`PatternCanvas/renderer.ts` 的 `#ece8e0` 板底），避免暗底干扰珠色判断；只有 UI 框架变暗
- 预处理页（图片裁剪/抠图）的纯黑底是功能色，两种主题下保持一致

**禁止使用：**
- `#FF8C42`（旧橙色，饱和度过高）
- `#FFFFFF`（纯白背景，过于冷硬）
- `rgba(0,0,0,...)` 作为 box-shadow（改用暖棕 `$shadow`）

## 三、字体规范

### 3.1 字号层级

| 层级 | 字号 | 字重 | 用途示例 |
|------|------|------|---------|
| 应用标题 | 21–22px | 700 | App 首页标题「拼豆图纸」 |
| 页面/区块标题 | 17px | 700 | 「我的图纸」区块标题 |
| 导航栏标题 | 16px | 600 | Topbar 中央标题 |
| 卡片标题/正文 | 15px | 600 | 入口按钮文字、图纸名称 |
| 辅助正文 | 13–14px | 400–500 | 参数标签、按钮辅助文字 |
| 提示/次要文字 | **12px（最小值）** | 400 | 入口按钮副标题、时间戳、工具提示 |
| 极小标签/徽章 | **10px（最小值）** | 400–500 | 尺寸角标、颜色代码标签 |
| 工具栏标签 | **11px（最小值）** | 400 | 工具栏图标下方文字 |

> 任何文字不得小于 10px。  
> 提示性文字（hint）最小 12px。  
> 工具栏标签最小 11px。

### 3.2 字体栈

```scss
font-family: -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Hiragino Sans GB', 'Noto Sans SC', sans-serif;
```

## 四、间距与圆角

### 4.1 圆角（Border Radius）

| 层级 | 值 | 用途 |
|------|----|------|
| 大圆角 `$radius-lg` | **20px** | 入口卡片、图纸卡片、主要容器 |
| 中圆角 `$radius-md` | **14px** | 区块面板、浮层、工具栏 |
| 小圆角 `$radius-sm` | **10px** | 工具栏按钮、标签芯片 |
| 微圆角 | 6–8px | 输入框、小型 badge |

> ⚠️ 主要容器不得低于 14px，入口/卡片类不得低于 20px。

### 4.2 间距节奏

| 用途 | 值 |
|------|----|
| 页面左右内边距 | 16px |
| 卡片/组件间距（gap） | 12px |
| 区块间距（section 上边距） | 20–24px |
| 卡片内边距 | 8–18px |
| 图标与文字间距 | 6–8px |

## 五、阴影

所有投影使用暖棕色调，禁止使用纯黑透明。

| 层级 | 值 |
|------|----|
| 标准卡片阴影 | `0 4px 16px rgba(150, 70, 30, 0.10)` |
| 轻阴影（面板、组件） | `0 2px 10px rgba(150, 70, 30, 0.08)` |
| 强阴影（主 CTA 按钮） | `0 4px 14px rgba(240, 135, 78, 0.32)` |
| 画板按钮阴影 | `0 4px 14px rgba(107, 168, 134, 0.25)` |

---

## 六、图标规范

| 用途 | 尺寸 | 颜色 |
|------|------|------|
| 工具栏功能图标 | **22×22px** | 非激活：`$text-dim`，激活：`$accent` |
| 入口卡片图标 | **24×26px** | 新建：`$accent`，画板：`$sage` |
| 颜色圆点（色板） | **28×28px**（圆形） | 对应颜色值 |
| 管理/操作图标 | **18–20px** | `$text-dim` |
| 导航返回文字 | 16px 文字 | `$accent` |

**图标样式：**
- 统一使用描边（stroke）风格，stroke-width: 1.8–2px
- 不使用 emoji 作为功能图标
- 图标颜色通过 CSS `mask-image` + `background-color` 控制（避免 `<Image src={svgDataUri}>` 走 setData）

## 九、禁止事项清单

- ❌ 背景使用 `#FFFFFF`（改为 `$bg: #FAF7F3`）
- ❌ 主色使用 `#FF8C42`（改为 `$accent: #F0874E`）
- ❌ box-shadow 使用 `rgba(0,0,0,...)`（改为 `$shadow: rgba(150,70,30,.10)`）
- ❌ 圆角低于 14px（主要容器）
- ❌ 任何文字低于 10px
- ❌ 提示类文字低于 12px
- ❌ 工具栏标签低于 11px
- ❌ 工具栏图标低于 22×22px
- ❌ 触控区域低于 44×44px
- ❌ 将橙色和鼠尾草绿混用（两者有明确语义区分）
- ❌ 使用 emoji 作为功能图标
- ❌ 将 SVG 数据 URI 通过 `<Image src={...}>` 传递（走 setData，改用 CSS mask-image）
