# 粗网格线格数误判修复

本次粗线修复仅修改图纸分析 Worker 的自动网格周期检测；不改图片转换的经典/保真算法或手动行列数。后续透明图的网格轮廓处理见 `ANALYZE_TRANSPARENCY.md`。

旧实现对亮度变化取绝对值，再统计相邻峰距。粗线两侧都产生峰值，线宽被当成格距，20 像素格距、3 像素线宽的 10×8 图纸因此误判为 67×53。

## 新检测

- 保留边缘的正负方向：进入粗线和离开粗线方向相反，不能充当相同的重复边界。
- 比较完整轮廓在候选周期下的相关性，要求足够的周期一致性；不足时返回既有的手动输入提示。
- 直接枚举行列数，允许非整数像素格距；仅在有相近证据且为整数倍周期时消除倍频，避免 80 格变成 81 格。
- 采样位置分层错开，避免全部扫描线恰好落在网格线上。

## 验证

- 原始复现：自动返回 10×8；页面得到 A04 共 80 粒。
- 20 像素格距下的 1–8 像素线宽均返回正确格数（这里验证格数，不保证极粗线遮挡后的底色仍可恢复）。
- 横竖不同格距、非整数缩放、裁剪偏移、亮线深底、多色底、每五格加粗线通过。
- Chrome 实际 PNG/JPEG、格内色号、页面自动识别流程通过。
- 平坦或随机轮廓拒绝自动推断；不足三个周期时需手动填写。

局限：面向已裁齐、水平垂直且等距的数字图纸。倾斜照片、透视、缺线、大面积图例和严重压缩仍可能失败或误判；相关性不是正确率保证。建议用户核对自动格数，不确定时手动输入。

回归入口：`npm test`、`scripts/test-analyze-grid.mjs`。浏览器脚本第一个参数为 Playwright 的 node_modules 路径，第二个可选参数为本地开发站点 URL。
