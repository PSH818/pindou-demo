## 1. 产品概述

### 1.1 背景

拼豆（熨烫珠 / Perler Beads / Hama Beads）是一种将彩色小塑料珠按图案排列在网格板上、加热熔合成型的手工艺品。创作的核心门槛在于**图纸设计**——需要将参考图手动转译为网格配色方案，耗时且需一定设计能力。

### 1.2 产品定位

面向拼豆爱好者的**图纸智能生成工具**，以"上传图片 → 自动转换 → 即时可用"为核心体验，覆盖从新手到进阶的全部创作场景。

Web 端运行，无需安装，浏览器直接访问即用。所有图像计算在本地完成，离线可用。

### 1.3 核心价值

> 上传一张图，30 秒得到一份可直接上手的拼豆图纸。

- **降低门槛**：不需要设计经验，任何图片都能转成图纸
- **精准落地**：输出与真实珠子品牌色号精确对应
- **即时导出**：图纸、用料清单、打印 PDF 一键生成
- **完全免费**：无账号、无配额、无付费墙，直接用

## 2. 目标用户

### 2.1 用户画像

| 用户类型 | 特征描述 | 核心诉求 | 使用频率 |
|----------|----------|----------|----------|
| 入门爱好者 | 刚接触拼豆，不会设计图案 | 快速把喜欢的图片变成可做的图纸 | 低，每周 1~2 次 |
| 进阶玩家 | 有经验，追求配色精准 | 精细调色、支持大尺寸、多品牌色板 | 高，每天使用 |
| 亲子用户 | 家长陪孩子做手工 | 简单操作，结果清晰，可打印 | 中，周末活动 |
| 创作者/卖家 | 制作并出售图纸 | 批量生产 + 便捷分享 | 高，每天使用 |

### 2.2 用户场景

- **场景 A**：看到一张卡通图，想做成拼豆送给朋友，不知道怎么设计图纸
- **场景 B**：买好了 Artkal C 系珠子，想转一张宠物照片做成摆件
- **场景 C**：孩子想做拼豆，家长帮忙把孩子画的画转成图纸打印出来
- **场景 D**：图纸创作者，需要快速批量出图纸发布到社群

## 3. 商业模式

### 3.1 完全免费

产品对所有用户永久免费，**无需注册、无需登录、无配额限制**。任何用户打开网站即可无限使用全部功能。

**原因：** 核心图像处理算法来自开源项目，遵循开源精神，不向用户收费。

### 3.2 可持续运营方式

| 方式 | 说明 |
|------|------|
| 自愿捐赠 | 在页面显眼位置放置捐赠入口（支付宝/微信），附上项目说明 |
| 广告位 | 预留广告位（不影响核心操作区域），视流量情况接入 |

> 捐赠和广告均为非强制性，不影响任何功能的使用。

## 5. 功能详述

### 5.1 图片输入

| 来源 | 支持格式 | 说明 |
|------|----------|------|
| 本地文件选择 | JPG / PNG / WEBP / GIF | 浏览器原生文件选择器 |

### 5.2 转换参数配置

#### 5.2.1 画布尺寸

| 类型 | 选项 | 实物尺寸（标准 5mm 珠） |
|------|------|----------------------|
| 预设 | 29×29 | 14.5 cm × 14.5 cm |
| 预设 | 45×45 | 22.5 cm × 22.5 cm |
| 预设 | 58×58 | 29 cm × 29 cm |
| 预设 | 72×72 | 36 cm × 36 cm |
| 自定义 | 1~200 × 1~200 | — |

宽高输入时实时显示对应实物毫米数。

#### 5.2.2 品牌色板

| 品牌 | 色系代号 | 颜色数 | 珠径 |
|------|----------|--------|------|
| MARD | MARD | 291 色 | 2.6 mm |
| COCO | COCO | 291 色 | 2.6 mm |
| 漫漫 | 漫漫 | 290 色 | 2.6 mm |
| 盼盼 | 盼盼 | 291 色 | 2.6 mm |
| 咪小窝 | 咪小窝 | 291 色 | 2.6 mm |
| Artkal Mini | C 系 | 108 色 | 2.6 mm |

国产五品牌使用同一份跨品牌 RGB 基准映射；这是色号对应关系，不代表各厂商珠子的独立实测色值。

#### 5.2.3 高级参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 最大颜色数 | 2 ~ 30 色 | 16 色 | 实际用色数 ≤ 此值 |
| 抖动（Dithering） | 开 / 关 | 关 | 开启后渐变更自然，有颗粒感 |
| 颜色合并阈值 | 0 ~ 100 | 30 | 值越大合并越激进，颜色种数越少 |

### 5.3 图纸编辑器

#### 5.3.1 视图模式

| 模式 | 说明 |
|------|------|
| 格子视图 | 纯色方格 + 可选颜色编号 |
| 模拟视图 | 圆形珠子渲染，接近实物 |

操作：滚轮缩放，拖拽平移。

#### 5.3.2 编辑工具

| 工具 | 交互 | 说明 |
|------|------|------|
| 画笔 | 点击 / 划动 | 用当前选中颜色覆盖格子 |
| 填充 | 点击 | 连通同色区域整体填充 |
| 吸管 | 点击 | 拾取格子颜色为当前选中色 |
| 橡皮擦 | 点击 / 划动 | 将格子置为透明（不放珠） |
| 撤销 | 按钮 | 最多 30 步 |
| 重做 | 按钮 | — |

#### 5.3.3 颜色面板

- 显示本图纸已使用的颜色列表（色块 + 色号 + 色名）
- 点击颜色：高亮显示图纸中所有该颜色的格子
- 添加颜色：从品牌色板中选择新颜色
- 删除颜色：将使用该颜色的格子置为透明

### 5.4 用料清单

- 按用量从多到少排列
- 每行：颜色预览 / 品牌色号 / 色名 / 用量（粒）
- 底部汇总：总粒数
- 操作：一键复制清单文本

### 5.5 导出

#### 5.5.1 导出图片（PNG）

| 选项 | 说明 |
|------|------|
| 标准（16px/格） | 适合手机参照 |
| 高清（48px/格） | 适合平板 / 打印参照 |
| 含网格线 | 默认开启 |
| 含颜色编号 | 格子 ≥ 20px 时可开启 |
| 含图例 | 底部附用料清单 |
| 含标尺 | 四边行列编号 |
| 含分组划线 | 每 5 或 10 格一条加重线，颜色可选（5 个预设色 + 自定义） |

触发浏览器下载对话框，保存到本地。

#### 5.5.2 导出 PDF（jsPDF 客户端生成）

- 第 1 页：图纸（A4，自动缩放适配）
- 第 2 页：用料清单（表格格式，可打印）
- 文件名：`{图纸名}.pdf`

### 5.6 本地存储

- 最多保存 50 张图纸（超出时提示删除最旧）
- 列表页：缩略图 + 名称 + 尺寸 + 更新时间
- 操作：重命名 / 复制 / 删除
- 恢复：点击历史图纸进入编辑器，恢复完整状态（含撤销栈）

## 6. 用户流程

### 6.1 核心流程（首次创建）

```
打开网站
    │
    ▼
首页 → 点击「新建图纸」
    │
    ▼
选择图片（本地文件）
    │
    ▼
参数配置
├── 选择画布尺寸
├── 选择品牌色板
├── 调整颜色数量（可选）
└── 点击「开始转换」
    │
    ▼（转换中，进度提示 ~3秒）
    │
    ▼
图纸编辑器
├── 查看图纸预览
├── 手动微调（可选）
└── 查看用料清单
    │
    ▼
点击「导出」
├── 选择格式（图片 / PDF）
└── 浏览器下载到本地
    │
    ▼
自动保存到「我的图纸」
```

### 6.2 二次编辑流程

```
首页 → 我的图纸 → 选择历史图纸 → 进入编辑器（恢复状态）→ 修改 → 导出
```

## 7. 非功能需求

### 7.1 性能指标

| 操作 | 目标耗时 | 备注 |
|------|----------|------|
| 29×29 图纸转换 | ≤ 3 秒 | Web Worker 内执行 |
| 100×100 图纸转换 | ≤ 10 秒 | Web Worker 内执行 |
| 编辑器缩放操作 | ≥ 30 fps | Canvas 渲染 |
| 导出 PNG（标准） | ≤ 2 秒 | 离屏 Canvas |
| 导出 PDF | ≤ 5 秒 | jsPDF 本地生成 |
| 背景去除（首次） | ≤ 60 秒 | 含模型下载 ~13MB（MODNet fp16） |
| 背景去除（后续） | ≤ 3 秒 | 模型已缓存 |

### 7.2 兼容性

| 浏览器 | 最低版本 | 说明 |
|--------|----------|------|
| Chrome / Edge | 90+ | 推荐 |
| Firefox | 90+ | — |
| Safari | 15+ | iOS / macOS |

需要：ES Module Worker、IndexedDB、Canvas 2D、File API。

### 7.3 存储限制

| 存储类型 | 限制 | 策略 |
|----------|------|------|
| 本地图纸 | 50 张（存储层硬限制） | 超出提示用户清理 |
| IndexedDB | 浏览器配额（通常 ≥ 1GB） | 无 5MB 硬限制 |
| 缓存（ONNX 模型） | ~13 MB | Cache API 持久化 |

### 7.4 离线能力

- 正式构建的 Service Worker 完成首次完整预缓存后，核心页面、色板、图纸转换／识别及导出代码可离线使用；首次访问仍需联网。缓存不足、未完成安装或被清理时不保证可用。
- 模型背景去除还需先成功下载并缓存模型与对应 WASM；不随应用离线安装预下载大模型。
- 用户图片只在浏览器本地处理，不上传到服务端。
- 开发服务不注册离线缓存；具体范围、验证与发布待办见 [整体验收与发布清单](./RELEASE_ACCEPTANCE.md)。
